# 匿名演示数据（合成）

本目录是 CostGuard 的内置演示数据：**全部由 `scripts/generate_demo_data.py` 程序生成**，
固定随机种子、时间戳归一化，任何人在任何机器上重新生成都会得到字节一致的文件。

> **声明**：本目录全部内容为合成演示数据，不包含任何真实公司、项目、人员、金额或
> 业务结构，不代表真实业务结论，仅用于功能演示与上手练习。

## 文件清单

| 文件 | 内容 | 方向 |
|---|---|---|
| 演示-对上结算-第1至3期.xlsx | 3 个期次 Sheet，覆盖文本数字、千分位、真零、缺失、负数、金额不符、一分钱舍入、公式无缓存、重复行、单位/单价/税率变化、漏项等 | 对上 |
| 演示-对下结算-第1至3期.xlsx | 3 个期次 Sheet，与对上同期号不同方向（方向隔离演示），含无编码行、缺名称行、缺失数量行 | 对下 |
| 演示-对下结算-附表.xlsx | 正常补充期次 + 「人材机汇总」Sheet（**刻意演示角色门控**：导入后需人工确认，程序不猜测） | 对下 |
| 演示-合同摘录-合成.docx | 全部虚构的合同条款摘录，条款提取结果带原文引用与段落位置 | 合同 |

`manifest.json` 记录每个文件的 SHA-256、方向、期次、预期解析行数、预期异常类型、
预期匹配结果、已知限制与 28 项场景覆盖矩阵；`SHA256SUMS` 是标准校验和文件。

## 怎么用

1. 启动 CostGuard，项目列表页点击 **「体验匿名演示」**（推荐），或手动新建项目后
   把本目录 3 个 xlsx 逐个导入（对上文件方向标记为"对上"，对下文件标记为"对下"）。
2. 依次点击「双向校核」「运行异常检测」「运行匹配」，在「匹配复核」处理不确定项。
3. 在「成果导出」导出 Excel 审核底稿和 Word 摘要。

「人材机汇总」Sheet 导入后会显示"待人工角色确认"——这是设计行为：CostGuard
遇到汇总/台账类表格不猜测角色，未经确认不写入正式结算模型。

## 可重复生成与校验

```bash
uv run python scripts/generate_demo_data.py            # 重新生成
uv run python scripts/generate_demo_data.py --check    # 校验与现有文件字节一致
shasum -a 256 -c SHA256SUMS                            # 校验文件完整性
```
