# Jiadun（价盾）v0.1.16 — 真实资料实测收口与异常定位预发行

## 本版定位

v0.1.16 是 v0.1.15 首个 Windows 交付版之上的阶段性预发行版和预览候选，内容来自
真实资料实测发现（随机抽取真实项目文件全链路实测）与用户现场需求：非常规文件
显式拒绝、公式类告警降级、异常→源文件单元格右键定位。本版不改变任何解析、计算
或校核行为。本版仍为 Preview/Prerelease，只适合合成或已经授权脱敏资料的试用、
规则验证和流程反馈，不代表正式结算、付款、责任、审批或经营结论。

## 主要变化

### 异常定位到源文件单元格（右键）

- 工作台异常表新增右键菜单：**打开源文件并定位单元格**（Windows 优先 COM：
  Excel → WPS 表格，只读打开并跳转到出错单元格）、**打开所在文件夹**、
  **复制单元格引用**（形如 `台账.xlsx::材料调差!F3`）。
- 打开前校验源文件 SHA-256：内容已变更则只打开所在文件夹并提示人工核对；
  原件被移动时自动回退项目内只读副本；未检测到可编程表格接口时仅打开文件
  并如实提示。macOS 暂不支持自动定位（只打开文件）。
- 溯源链：异常 → Sheet → 解析批次 → 源文件（含 SHA-256），行列取自异常记录
  中的「Sheet『名』单元格(行,列)」信息。

### 非常规文件显式拒绝

- PDF/DOCX 合同解析前置魔数校验：同步残留、损坏或误命名文件给出明确中文
  提示，不再抛解析器裸异常。

### 公式类告警降级

- WPS 保存的工作簿普遍不缓存公式值，formula_no_cache / formula_untrusted_cache
  属常见保存行为而非金额错误：严重级别由 high 降为 low（formula_error 仍为
  high），缓解真实资料中数百条告警淹没重点的问题。

## 升级与兼容

- 无数据库结构变更、无配置变更；从 v0.1.13/v0.1.14/v0.1.15 直接覆盖安装即可。
- 项目数据库、原始文件与历史导出不受影响；卸载只删除程序目录，用户数据
  `Documents\JiadunProjects` 永不清除。

## 安全提示

Windows 安装包与便携包**均未签名**：SmartScreen 可能提示"未知发布者"，部分
杀毒软件可能对 PyInstaller 产物误报；请通过 Release 页的 SHA256SUMS.txt 核对
哈希后使用。

## 安装和兼容

- macOS Apple Silicon：`Jiadun-0.1.16-macos-arm64.dmg`
- Windows x64 安装版：`Jiadun-0.1.16-windows-x64-setup.exe`（按用户安装，双击
  即可，无需管理员）
- Windows x64 便携版：`Jiadun-0.1.16-windows-x64-portable.zip`（解压即用）

下载后使用同一 Release 中的 `SHA256SUMS.txt` 校验。旧 `costguard` 图形命令、
GitHub 仓库地址、历史 tag、旧项目目录和旧导出文件保留兼容意义；升级不会删除、
覆盖或移动原始工程资料。
