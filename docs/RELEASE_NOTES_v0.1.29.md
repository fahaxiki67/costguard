# Jiadun（价盾）v0.1.29 — 税口径模型预发行

## 本版定位

v0.1.29 是在 v0.1.28 基础上的「任务 C：税口径模型」版本（结构版本 v55，
运行合同格式 v3，用户反馈#4），仍为预览候选。macOS Apple Silicon 仍是
P0 主平台，Windows x64 仍是 P1。本版不标记为正式生产版。

## 主要变化

### 税口径结构化与识别（任务书任务 C，schema v55）

- Sheet 级税口径：未确认（默认）/含税/不含税，附来源（自动/人工）、
  依据、时间与操作人。「单价通常不含税」只是业务候选，无明确文本证据
  不自动认定。
- 表头明确文本自动识别：含税单价/不含税合价/价税合计等说法构成依据
  （已处理「不含税」包含「含税」子串的误判）；导入时写入并记审计
  Evidence；重导入不覆盖人工标注。
- 独立税金/税额列：表头识别后登记到明细行（tax_amount），只记事实、
  不据此推断口径；税率数值（如 9%）永远不是金额口径。
- 人工改判：「全工作簿 Sheet 清单」对话框新增税口径列与下拉，理由必填
  写 Evidence；重解析时人工税口径随内容一致结转保留。
- 口径变化 → Run Contract 签名变化 → 旧运行自动失效（不同口径金额不可
  混用）；口径未确认/不一致时，比较层据 tax_basis_comparable 降级
  PENDING / INCOMPARABLE，不直接判定 PASS/FAIL。

### 继承能力

v0.1.28 Sheet 清单浏览器、v0.1.27 角色确认/结转/合同失效联动、v0.1.26
性能修复及之前全部能力保留。
