# Jiadun（价盾）v0.1.0 — 首次开源开发者预览（历史版本）

> 兼容说明：本文记录 v0.1.0 当时的发布内容，当时产品名称为 CostGuard；现行产品名称
> 为 Jiadun（价盾）。已发布的历史资产名称和 Git 历史保持不变，不表示远端资产已经改名。

Jiadun（价盾）是面向工程结算核对的本地桌面工具。本次首发聚焦一条可复核主链：

`Excel 导入 → 清单字段标准化 → 工程量/单价/总价校核 → 同义材料归并 → 对上对下差异 → 异常项识别 → 导出报告`

## 本次可用能力

- 导入 `.xlsx`、`.xls`、`.csv`；原文件只读，导入副本带 SHA-256。
- 识别多行表头和常见字段别名，保留原始 Sheet、行列和单元格值。
- 使用 `Decimal` 复算数量 × 单价与金额，缺失值不填 0，差异不调平。
- 按编码、规范化名称、单位和人工别名归并清单；不确定结果显示置信度并进入复核。
- 对上、对下按独立方向和期次累计，输出工程量、单价和金额差异。
- 运行异常规则并保留 Evidence ID、处理状态和人工原因。
- 导出带边框、居中、数字格式和证据索引的 Excel 审核底稿，以及 Word 摘要。

## 首发限制

- 本次发布源码和 Python wheel，尚无签名、公证的 macOS DMG。
- 首发优先支持 macOS Apple Silicon；Windows 安装包后续提供。
- 旧版 `.doc`、扫描件 OCR 尚未实现；PDF/Word 条款提取仍要求逐条核对原文引用。
- 非标准汇总表、核销台账等可能进入“角色/字段待确认”，程序不会猜测后直接写入正式清单。
