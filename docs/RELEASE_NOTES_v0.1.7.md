# Jiadun（价盾）v0.1.7 — 可信校核与审核工作流预览（历史版本）

> 兼容说明：本文记录 v0.1.7 当时的发布内容，当时产品名称为 CostGuard；现行产品名称
> 为 Jiadun（价盾）。历史安装物、项目路径和远端资产按当时事实保留，不表示远端资产
> 已经改名。

## 本版定位

v0.1.7 是面向审核可信度和人工复核效率的预览候选版本。它收紧了双向
校核的证据门槛，补齐了长清单浏览、问题处理和成果导出的关键路径，仍不
应标记为正式生产版。

## 主要变化

- 清单明细按页加载，显示总记录数和当前显示区间；搜索、筛选和人工复核
  作用于完整数据集，导出不受页面分页影响。
- 双向校核区分“校核充分 / 校核有发现 / 校核不充分”。A/B 一致不再直
  接等同于结算正确；C 控制不可用、控制差异、待确认工作表或取数范围无
  法证明时，会保留限制并禁止显示纯绿色通过。
- 校核结果保存参与明细行数、排除小计行数、排除标题说明行数、待确认工
  作表数量、C 控制状态和证据标识，项目重开后仍可追溯。
- 审核底稿并列保留程序 Decimal 计算值和 Excel 复核公式值，主审核结论
  不依赖 Office 首次打开时重新计算。
- 业务界面统一使用“对上结算 / 对下结算 / 未标记”和中文问题状态；异
  常中心支持“已核实无问题 / 已补资料 / 已修正 / 暂不处理”，并保留处理
  原因和审计记录。
- 项目首页和工作台增加审核总览、下一步建议、清单证据详情、左右匹配复
  核、真实工作表字段样例和成果生成状态。
- 新增运行契约（Run Contract）：源文件 SHA-256、工作表范围、字段映射、
  期次与方向、合同事实、明细输入、规则配置、Schema 和代码版本共同形成
  运行签名。校核、异常、匹配和 Excel/Word 成果只读取当前签名，输入或配置
  变化后旧成果保留为历史并标记失效。
- 异常与风险统一使用 Finding/Evidence 字段，保留稳定 `finding_id`、问题
  指纹、置信度、检测方式、原始值、标准化值、影响、限制、建议和抑制原因，
  方便重复运行后的问题归并与人工回查。
- 提供可中断的 1万/5万/20万行基准脚本和发布一致性检查脚本；目标环境的
  实测数据仍待补齐，未执行的规模不会被写成通过。
- 异常规则检测与 A/B/C 聚合验证分别记录预期、已执行、明确跳过和失败项；
  覆盖不完整时工作台、Excel 和 Word 均维持待复核门控。
- 新增权威批次清单、复合键重复阻断、清洗变更事件、有限公式图谱、第二读取器
  隔离试验和 P2 复核排序接口。第二读取器与排序试验默认不改变主读取或自动确认
  结果，公式图谱遇到动态/超限引用时失败关闭。

## 已知发布门槛

以下项目尚未完成，不能据此宣称生产就绪：

1. WPS、macOS Excel、Windows Excel 真机打开、重算和显示专项验证。
2. 1万、5万、20万清单行的导入、打开、搜索、异常、匹配、校核和 Excel
   导出性能基准，以及长任务进度和安全取消验证。
3. macOS Developer ID 签名与 notarization、发布 CI、版本迁移/备份恢复和
   异常退出恢复测试。
4. 真实案例回归及独立复核遗留问题的关闭。

在证据条件充分并完成上述门槛前，本版本只作为预览/Beta 候选使用。缺失、
待补资料和不可比项目保持原状态，不以 0 替代。
