# ADR-008: 两段式解析（保真层 + 语义层）
状态: Accepted | 日期: 2026-08-29
## 决策
1) 保真层：openpyxl 双读（data_only False/True），逐格落库 raw_cells，
   保留公式缓存值、文本数字标记、合并单元格拓扑、隐藏行列。
2) 语义层：表头识别 → 列映射（带 confidence）→ 抽取 line_items 并记录每字段出处。
语义层可在保真层上随时重放，不改原始数据。
## 理由
真实结算表结构千奇百怪（多层表头、任意起始行、合并单元格）。把"读"与"懂"分开，
识别错误可修复重放，不丢信息；字段级出处直接支撑证据链。
