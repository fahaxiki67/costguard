# ADR-009: License 暂缓决定（GPL-3.0 vs Apache-2.0）
状态: Accepted (deferred) | 日期: 2026-08-29
## 决策
公开仓库前不设 LICENSE 文件（当前 license=Proprietary 占位）。对比结论供用户拍板：
| 维度 | GPL-3.0 | Apache-2.0 |
|------|---------|------------|
| 商业使用 | 允许，但衍生品须开源同协议 | 允许，可闭源衍生 |
| 修改后再发布 | 必须 GPL | 任意，需保留声明 |
| 闭源衍生 | 禁止 | 允许 |
| 专利授权 | 隐含+反 tat 条款 | 明确专利授权+防御终止 |
| 对项目影响 | 强 copyleft，生态改动全部回灌，企业采用意愿低 | 宽松，利于社区/企业采用，衍生可能闭源 |
## 建议
若期望社区与生态广度、被集成：Apache-2.0；若坚持所有改进开源：GPL-3.0。
最终由用户决定，届时本 ADR 更新为 Accepted(chose)。
