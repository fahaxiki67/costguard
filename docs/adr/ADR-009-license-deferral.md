# ADR-009: 采用 Apache License 2.0
状态: Accepted | 日期: 2026-08-30
## 决策
Jiadun（价盾）首次公开发布采用 **Apache License 2.0**。仓库根目录提供完整
`LICENSE`，项目元数据使用 SPDX 标识 `Apache-2.0`。

此前“首次只建私有仓库、许可证暂缓”的决定已被用户“先发布可用 V1、后续持续
迭代并获得真实用户/Star/下载/Issue”的开源目标取代。

开源备选对比如下：
| 维度 | GPL-3.0 | Apache-2.0 |
|------|---------|------------|
| 商业使用 | 允许，但衍生品须开源同协议 | 允许，可闭源衍生 |
| 修改后再发布 | 必须 GPL | 任意，需保留声明 |
| 闭源衍生 | 禁止 | 允许 |
| 专利授权 | 隐含+反 tat 条款 | 明确专利授权+防御终止 |
| 对项目影响 | 强 copyleft，生态改动全部回灌，企业采用意愿低 | 宽松，利于社区/企业采用，衍生可能闭源 |
## 理由与边界
- 宽松许可更利于个人、工程企业和第三方工具采用、试用与集成。
- 明确的专利授权和防御终止条款比仅使用宽泛的“免费使用”声明更清晰。
- 允许闭源衍生是扩大采用面的代价；上游改进是否回流仍依赖社区协作，而非许可证强制。
- 许可证只授权代码和仓库中的公开文档/合成样例；任何真实合同、结算资料、个人信息和
  `local_private_data/` 均不属于开源发布内容。
