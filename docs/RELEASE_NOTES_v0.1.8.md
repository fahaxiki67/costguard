# Jiadun（价盾）v0.1.8 — 复核闸门与恢复边界预发行

> 改名说明：v0.1.8 最初以 CostGuard 名称发布在现有 GitHub Release；当前产品名称为
> Jiadun（价盾）。本文采用现行品牌便于后续维护，已有 tag、Release 和远端资产名称
> 保持历史事实，不表示远端资产已经改名。

## 本版定位

v0.1.8 是在 v0.1.7 基础上的预发行版本和预览候选，重点修复复核闸门、当前运行结果和失败恢复边界。它适合使用匿名或合成资料进行试用和反馈，不标记为正式生产版。

## 主要修复

- 未来数据库 `schema` 版本会立即失败关闭。旧程序不会打开未来库，也不会把项目版本标记降写。
- 期次方向修改、带别名的匹配确认和批量匹配确认统一使用核心事务。审计、Evidence、运行契约和业务状态任一环节失败时，整次操作回滚。
- 批量确认在实际写入前重新读取当前 `level` 和 `status`，并在最终更新条件中再次锁定 `level=confirmed`、`status=pending`；并发或触发器改变任一行时整批回滚。
- `save_matches()` 增加核心层当前结果可用性门控。运行级不可用时，其他入口不能绕过界限写入匹配候选。
- A/B/C 覆盖率保留未声明键并失败关闭。项目级校核一次协调上下方向，避免相同期号在不同方向下无法形成完整项目证明；显式方向的部分期次重跑会使项目范围的旧校核结果退出当前读取面，必须重新完成项目全部期次后才能恢复闸门；`period_totals` 缺行会被识别为持久化失败。
- fail-closed 边界只能由聚合校核运行产生的、绑定当前项目全部期次和真实业务行/证据的完整 A/B/C 覆盖证明解除；普通异常检测覆盖和调用方自报的聚合运行类型不能代替该证明。
- 权威批次清单增加解析批次、Sheet、期次、方向和表头语义核对。文件名或 SHA-256 一致不再单独证明业务语义正确。
- Excel 和 Word 导出先写入同目录临时文件；`export_runs` 登记失败时，不留下本次未登记的成品文件。
- 导出封面、Word 摘要和性能报告读取当前版本号，避免继续显示 v0.1.7。

## 本地验证

当前候选已通过 427 项自动化测试、Ruff 检查、Python 编译检查和差异空白检查。新增测试覆盖混合方向项目级校核、显式方向部分重跑失效、聚合覆盖率伪造防护和批量确认并发回滚。测试使用隔离的临时数据库与合成数据，不代表任何真实项目金额、结算、责任或审批结论。

## 独立复核结论

本次代码级独立复核结论为「有条件通过」：P0-04、P1-01、P1-02 已关闭，当前复核范围内未发现同类阻断。部分期次重跑后，`periods_unchecked`、聚合覆盖和自动分析会保持失败；`verification.status` 仍可能针对保留的已检查子集显示 `sufficient`，该字段语义作为产品边界观察保留，不得把它解释为项目整体完成。

独立复核使用隔离 SQLite 与合成数据，结论不等同于真实项目、Office 真机、性能、签名、公证、迁移恢复或审批验收。完整复核记录保存在仓库内部 SDD 记录中。

## 尚未完成的预发行门槛

以下项目仍需在目标环境单独验证，完成前不能把本版本称为正式生产版：

1. WPS、macOS Excel、Windows Excel 真机打开、重算和显示专项验证。
2. 1万、5万、20万清单行的导入、搜索、异常检测、匹配、校核和 Excel 导出性能，以及长任务进度和安全取消。
3. macOS Developer ID 签名、公证、发布 CI、版本迁移、备份恢复和异常退出恢复。
4. 真实案例回归和外部验收；本次代码级独立复核已完成，结论为有条件通过，不替代上述环境门槛。

## 使用边界

- 预发行版本只建议用于匿名或合成资料试用。未经人工复核和业务审批，自动结果不构成正式结算、付款、考核、责任认定或经营结论。
- 缺失资料保持「待补资料」，不可比数据保持「不可比」；程序不会用 0 补齐缺失值，也不会为了调平差异而修改金额。
- 预发行 DMG 为 Apple Silicon 原生、ad-hoc 本地签名、未完成 Apple 公证的安装包。首次启动可能需要在 Finder 中右键选择「打开」。
