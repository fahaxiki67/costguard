# CostGuard v0.1.5 — Windows x64 安装包（未签名）

Windows x64 的第一个安装包版本。与 macOS 版**共享同一核心引擎、数据模型、
测试与界面**（AGENTS.md：不拆成两个软件），平台差异只存在于 `platform/`
层与打包脚本；全部纪律（缺失不填零、金额 Decimal、对上对下隔离、原始文件
只读、证据链与人工确认门控）由同一套测试锁定，未做任何退化。

## 本次新增

- **CostGuard-0.1.5-windows-x64-setup.exe**（Inno Setup 安装器）与
  **便携版 zip**：双击安装（可选"仅当前用户"，无需管理员），开始菜单/桌面
  快捷方式，卸载只删程序目录——**用户工程数据 `Documents\CostGuardProjects`
  永不触碰**。无后台常驻、无自动更新、无驱动。
- **真实验证（windows-latest runner）**：全量 pytest、ruff、构建、PE x64
  架构校验、隐私审计、匿名演示端到端（导入→字段标准化→工程量/单价/总价
  Decimal 校核→同义材料归并→对上对下差异→异常识别→Excel/Word 导出）、
  静默安装→启动→退出→卸载冒烟、敏感信息扫描、SHA256。
- **Windows 测试进 PR 门禁**：`ci.yml` 新增 windows-latest job，每次 PR 都在
  真实 Windows runner 上跑全量测试。
- **人工确认工作表 GUI**（移植自 Windows 协作者补丁，issue #5）：导入后对
  表头歧义/无表头/表单类工作表，可在"人工确认清单页"里查看待确认列表
  （区分"表头歧义待复核/无表头"两种状态）、预填或人工指定 8 字段列映射与
  表头行范围、标记方向期次，然后"按结算清单抽取"或"仅存证（非结算角色）"；
  原因必填并写入审计日志——上游 GUI 此前完全没有这个入口。
- 小计词补充"本页小计/本页合计"（支付报表按页小计行）。
- 演示数据生成器 Windows 修复：zip 条目 `create_system=3`（否则 Windows
  生成字节与 macOS 不一致、确定性校验必挂）+ `os.replace` 杀软锁退避重试
  （issue #9 场景，GitHub issue #9 可随之关闭）。

## 版本谱系更正（交付包文档勘误）

Windows 协作者交付包内的说明存在版本表述互相矛盾（启动器 BAT 写"基于
v0.1.2 + 7 项修复"、说明文档写"v0.1.3 + 3 项"、补丁文件名叫
v0.1.2）。**正确谱系是：上游 v0.1.3（6a3da73）基线 + 3 项增强**
（人工确认 GUI、演示生成器两处 Windows 修复、小计词补充）；其 #1/#3/#6/
#2短期的同名修复已随上游 v0.1.3 发布、在补丁中退役。本 v0.1.5 以最新
main（v0.1.4）为基线只移植仍必要的上述 3 项，未采纳旧源码快照。

## 签名边界（如实说明）

- 当前 Windows 安装器**未做代码签名**：首次运行 SmartScreen 可能提示
  "已保护你的电脑"——点"更多信息 → 仍要运行"；不同系统设置提示形态不同，
  **不能承诺完全不出现提示**。
- 代码签名证书属后续版本工作；签名材料只从本机或 GitHub Secrets 读取，
  绝不入库。

## 验证状态

- macOS arm64 与 Windows x64 双 runner：全量测试全绿、ruff 全绿（Windows
  runner 的确切数字以发布时 CI run 为准，见下方链接）。
- 安装器与便携 zip 的 SHA-256 见随发布上传的 `SHA256SUMS.txt`。
- 自动计算结果是技术校核结果，必须经人工复核与业务审批，不构成已批准
  业务结论；扫描 PDF/图片 OCR 仍未实现（会明确提示而非静默返回空结果）。

## 升级与数据安全

- 工程数据保存在用户本机 `Documents\CostGuardProjects`，与程序分离；
  卸载程序不影响项目资料。
- 软件不做后台静默更新；新版本由用户自行决定。
