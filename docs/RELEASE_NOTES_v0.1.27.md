# Jiadun（价盾）v0.1.27 — Sheet 角色确认服务层预发行

## 本版定位

v0.1.27 是在 v0.1.26 基础上的「任务 B：Sheet 选择与角色确认」服务层版本
（结构版本 v54，运行合同格式 v2），也是一个预览候选。长期平台战略保持
不变：macOS Apple Silicon 仍是 P0 主平台，Windows x64 仍是 P1。本版不
标记为正式生产版。

## 主要变化

### Sheet 角色确认（任务书任务 B 服务层，schema v54）

- 全工作簿 Sheet 清单：列出项目全部 Sheet（不只待确认门控页），附可见
  状态（visible/hidden/veryHidden；历史批次为「未知」，不默认可见）、
  行列数、建议角色、置信度（高/中/低，启发式分级）、推荐理由（含表头
  特征提示）与当前人工标注。
- 角色枚举扩展：新增对上明细/对下明细/其他费用，连同原有分部分项、
  单价措施、总价措施、汇总页、非业务共 9 种；不建立第二套枚举。
- 过滤模式：全部 / 仅待确认 / 仅建议参与分析（明细类建议）。
- 重解析人工决策结转：同文件再次导入时，同名且单元格内容摘要一致的
  Sheet 自动沿用原人工确认（状态与角色）；内容变化或无同名旧页一律
  重新确认。机器建议永不覆盖人工标注。
- 合同失效联动：清单类型纳入 Run Contract 范围（格式 v2），角色变更即
  签名变化，旧运行自动失效，旧结果不得伪装为当前分析。确认动作写入
  完整 Evidence（来源文件+哈希+机器建议+人工理由+时间戳）。
- 摘要安全补丁：新增缓存失效触发器——raw_cells 的任何写入都会删除对应
  Sheet 的摘要缓存，防止陈旧摘要掩盖内容漂移（漂移检测回归已验证）。

### 继承能力

v0.1.26 及之前的性能修复（F-3 缓存化）、Sheet 清单类型标注、合同确认
生命周期、逐页对照复核、对上控制基准、费率规则等全部保留。

## 升级影响

旧项目打开后自动迁移到 v54（迁移前自动备份）。迁移会为运行合同引入
格式 v2：旧运行的签名全部失效并在下次校核时重建（角色语义变化的有意
行为，业务数据与 Evidence 不受影响）。
