# 真实资料端到端验收

本文件规定 CostGuard 在 Mac Apple Silicon 版本进入打包或发布准备前，必须完成的本地真实资料验收。合成测试通过不等于软件已经满足真实工程资料的使用要求。

## 执行时点

满足以下条件后，执行真实资料验收：

1. 当前开发阶段完成，并通过单元测试、集成测试和回归测试。
2. 已修复监督检查发现的零值、缺失值、方向隔离和导出勾稽问题。
3. 软件可以在 macOS Apple Silicon 环境中完成完整业务流程。
4. 测试不需要登录 GitHub，也不需要创建远程仓库、推送、发布 Release 或改变权限。

未满足以上条件时，不要为了提前展示效果而导入大量真实资料。

## 安全边界

- 原始文件始终只读。不得修改、覆盖、重命名、移动或删除原始文件。
- 从原始文件制作测试副本。测试副本放入 `local_private_data/real_acceptance/corpus/`。
- 测试数据库、日志、缓存和导出结果放入 `local_private_data/real_acceptance/work/`。
- `local_private_data/` 不得进入 Git、GitHub、CI、云盘或外部服务。
- 不选择身份证、银行账号、密码、API Key、Token、私钥、签名证书、医疗资料、纯私人照片或与工程经营无关的隐私文件。
- 真实资料的自动计算结果只属于测试结果。除非经过人工复核和业务审批，不得表述为最终结算、最终损失、最终考核、责任认定或正式管理结论。

## 测试资料选择

测试语料使用少量、差异明显、可解释的文件。不要简单复制整个硬盘或整个项目目录。

至少覆盖以下类型：

| 类型 | 需要覆盖的特征 |
| --- | --- |
| `.xlsx` | 多期、多 Sheet、多行表头、公式和缓存值、隐藏行列、合并单元格、文本数字、空值、真零、负数、税率变化、单位变化 |
| `.xls` | 旧版二进制工作簿的导入、Sheet 枚举、数值和日期读取 |
| `.csv` | 编码、分隔符、空字段、文本数字和大批量行 |
| `.docx`、`.doc` | 合同条款、表格、段落位置、原文引用和缺失条款 |
| 文本型 `.pdf` | 页码定位、条款原文引用和表格提取 |
| 扫描型 `.pdf`、图片 | OCR 失败边界、置信度、人工复核入口和原图定位 |
| 跨文件组合 | 对上与对下、不同期次、同名异码、同码异名、缺一侧、税率或单位不一致 |

候选资料优先来自已经完成过人工核查、存在可追溯结果的工程结算和合同资料。这样可以用已知事实核对程序结果。不要只选择结构整齐或程序已经熟悉的文件。

## 测试前记录

在 `local_private_data/real_acceptance/manifest.csv` 中逐文件记录：

- 测试编号；
- 原始文件名称；
- 原始文件所在目录的本地标识；
- 测试副本相对路径；
- 文件类型和文件大小；
- 原始文件与测试副本的 SHA-256；
- 选择原因；
- 预期覆盖的解析或业务场景；
- 已知人工核查结果；
- 敏感信息检查状态。

原始文件路径只保存在 `local_private_data/`。不要把本地绝对路径写入可提交文件。

## 端到端流程

每组真实资料按以下顺序测试：

1. 复制原始文件并校验 SHA-256。确认原始文件和测试副本内容一致。
2. 创建全新的测试项目。不得复用生产项目数据库。
3. 导入测试副本。确认软件未修改原始文件和测试副本。
4. 检查文件、Sheet、页码、行列、段落、公式、缓存值、隐藏状态和合并区域是否完整记录。
5. 检查结构化结果。区分空值、真零、不可比和待补资料。
6. 使用 `Decimal` 重新计算数量、单价、金额和累计值。
7. 使用独立路径复核关键金额。记录两条路径的结果和差异，不得人为调平。
8. 运行异常规则。检查遗漏、误报、重复、单位变化、税率变化和舍入差异。
9. 运行匹配。检查五档置信度、反例和人工复核入口。
10. 解析合同。每项合同事实必须带原文、页码或段落位置以及证据 ID。
11. 导出 Excel 和 Word 成果。使用 WPS 实际打开、重算和保存副本。
12. 从导出结论反向追溯到原始文件、Sheet 或页码、行列或段落以及原始内容。

## 通过标准

只有同时满足以下条件，才可以把真实资料验收标记为通过：

- 原始文件哈希在测试前后保持一致。
- 支持范围内的文件能够导入；不支持的文件给出明确、可恢复的提示。
- 缺失值未被填充为 `0`，真零未被识别为缺失值。
- 金额计算使用 `Decimal`，并完成至少一条独立复核路径。
- 对上、对下、期次、单位和税口径未发生串表或混用。
- 异常规则和匹配结果包含反例测试，不以修改测试迁就错误实现。
- 合同事实可以定位到原文。
- 导出文件能够在 WPS 中打开和重算，公式、数字格式和中文 Sheet 名保持可用。
- 每项失败、差异、误报、漏报和限制均有记录；未查明差异保持「无法确认」或「待补资料」。

## 交付记录

测试结束后生成本地验收报告。报告至少包含：

- 测试环境和软件版本；
- 测试语料数量和类型；
- 每个文件的导入、解析、计算、异常、匹配、合同和导出结果；
- 双路径复核结果和差异；
- 失败步骤、错误信息、恢复方式和复测结果；
- 已知限制和暂不支持范围；
- 是否达到 Mac Apple Silicon 本地使用条件。

验收报告不得包含真实敏感内容，不得自动上传或公开发布。GitHub 发布仍需用户在执行远程创建、推送或 Release 前单独确认。
