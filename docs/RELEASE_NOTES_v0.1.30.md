# Jiadun（价盾）v0.1.30 — 结算累计表口径标注预发行

## 本版定位

v0.1.30 是在 v0.1.29 预览候选基础上的小版本预发行，补齐 Issue #4③ 的导出可见性：
累计表明确展示参与累计的明细行数、排除的小计行数和当前校核级别。本版仍是预览候选，
不代表正式生产能力。

## 主要变化

- 对上/对下结算累计表在表尾追加行数口径与校核级别说明，不改变既有首行数据读取面。
- 没有当前校核结果时输出“行数口径不可用（不视为通过）”，不补值、不静默给出肯定结论。
- 数据库表损坏、迁移缺失或 schema 漂移等读取异常单独呈现，和“没有校核结果”保持可区分。

## 验证结果

- PR CI：全量 pytest、Ruff、macOS arm64、Windows x64 通过；Windows x64 打包流水线通过。
- 本 Release 由维护者在 `main` 上打 tag，并以独立平台构建产物和 SHA-256 清单发布。

- macOS Excel、Windows Excel、macOS WPS、Windows WPS 真机验收。

以上门槛未闭合前，本版保持 Preview/Prerelease；不能解释为 production ready。
