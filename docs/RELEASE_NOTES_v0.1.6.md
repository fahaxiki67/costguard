# Jiadun（价盾）v0.1.6 — 真实结算书正确性与界面专业化（macOS，历史版本）

> 兼容说明：本文记录 v0.1.6 当时的发布内容，当时产品名称为 CostGuard；现行产品名称
> 为 Jiadun（价盾）。历史项目路径、应用名称和远端资产按当时事实保留，不表示远端资产
> 已经改名。

本版本闭环 v0.1.5 发布说明登记的已知限制（C 路径控制值翻倍），并按独立
复核意见完成一轮正确性/界面专业化修复。全部基于真实结算书（229 Sheet）
实测驱动；与 Windows 版共享同一核心引擎，纪律零退化。

## 修复（对照 v0.1.5 已知限制与复核发现）

- **C 路径控制值不再翻倍**：控制值只取唯一"合计级"行（合计/总计/累计）；
  无合计级行时按页级小计互斥求和；多个合计级行 → 明示"不唯一，待人工"；
  页小计未覆盖全部明细 → 差额如实报 diff，不调平。
- **E.6 单位工程汇总表（真实 26 页）不再被误判为表单**：全部进入"待人工
  角色确认"，可经「人工确认清单页…」处理。
- **无金额列的工作表（表-09 综合单价分析页等）不再自动解析**：此类页写入
  的明细无法参与金额校核，现一律待人工确认——口径以本条为准。
- 含冒号特征文本的小页表-08 不再被误判为表单；"第N页小计"/排版空格小计
  标签正确识别；分部标题行不再混入明细（跳过原因逐表记录）。

## 界面专业化（仅展示层）

- 统一视觉系统：主色 #2563EB、按钮四层级、表格行高 32/列宽策略化、
  语义浅底徽章（高=浅红/中=浅橙）。
- 业务语言展示：规则/匹配方法/级别/状态全部中文（内部代码保留于 Tooltip）。
- 双向校核消息逐期显示 **C 控制值与控制状态**；A/B 一致但控制差异存在时
  显著警示，不再被一致状态遮住。
- 人工确认清单页视觉分组，列映射显示"第 N 列 · 表头名"，自动识别候选
  浅蓝底标识，人工修改即时还原。

## 明确声明（独立复核意见照实登记）

- **解析工作表数 ≠ 结算期数**：一个结算书解析出 N 张表，期次由人工逐表
  指定后按（方向，期号）聚合。
- **A/B 两路径共用同一抽取器**：可校验解析保真与聚合正确性，不能证明
  "行集选择正确"——行集正确性由 C 控制值与人工确认兜底；真正的独立第三
  路径已立项（issue #4）。
- T17 实测中"同一清单项出现在多个分部"为源表真实结构（抽取行与原始网格
  行 1:1 对应，已逐页核验），不构成重复计入。
