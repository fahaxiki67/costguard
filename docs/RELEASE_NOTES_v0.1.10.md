# Jiadun（价盾）v0.1.10 — 证据闸门深化预发行

## 本版定位

v0.1.10 在 v0.1.9 品牌迁移版本上深化本地结算复核能力。重点是让当前结论、
历史结果、人工确认和来源证据使用明确的运行边界，并为清单差异、匹配复核、
规则配置、项目版本和历史综合单价提供可追溯的本地数据结构。

本版仍是预览候选（Preview/Prerelease）。适合使用合成或已授权脱敏资料进行试用、规则验证
和流程反馈，不代表正式结算、付款、责任、审批或经营结论。

## 主要变化

- 每次运行使用唯一 `run_id` 和不可变 Run Contract。输入恢复为历史相同签名时，
  系统仍创建新的运行记录，不会重新激活旧运行。
- Run Contract 固定文件 SHA-256、Sheet 范围、原始网格摘要、表头和字段映射、
  期次方向、规则配置、Decimal 精度和舍入、别名、人工确认及项目版本。
- 每个结算 Sheet 保存覆盖证明和逐行分类，区分明细、小计、合计、标题、备注、
  空白、尾注、孤立数值、解析失败、待确认和未识别行。
- A、B 共用同一抽取行集时明确标记非独立。缺少 C 控制值、范围证明或必要
  Evidence 时，期次保持「校核不充分」。
- UI、Excel 和 Word 共用 Sheet、期次、方向、项目四级状态。历史结果保留，
  但不进入当前金额、Finding 数量或项目结论。
- 增加清单差异雷达、左右镜像匹配、字段映射模板、别名知识库、规则目录和
  Finding 处理事件。人工确认继续记录操作人、时间、前后值和原因。
- 增加项目版本链、最终审定快照和历史综合单价提示。历史价格只用于提示复核；
  地区、时间、专业、特征或计量口径不一致时，不直接比较，也不自动认定错误。
- 增加黄金回归、发布检查清单和 1 万、5 万、20 万行分阶段性能测试工具。

## 计算和 AI 边界

- 金额、数量和单价继续使用 `Decimal`，不使用 `float` 参与业务计算。
- 缺失资料保持「待补资料」，不可比较的数据保持「不可比」，不以 0 补齐。
- 原始文件不修改。所有成果写入独立工作目录。
- AI 只可用于语义候选和文字解释，不承担金额计算、最终匹配、自动补缺、
  正式结论或责任判断。

## 已验证范围

本地候选执行自动化测试、Ruff、发布一致性检查、合成黄金案例和发布资产隐私
检查。程序会把未运行、条件通过和不可用的外部门槛保留为限制，不把它们写成通过。

本次候选现场记录：

- 全量自动化测试：560 passed；Ruff、迁移/备份恢复、异常退出/取消测试通过。
- 合成黄金回归：1 个合成案例通过；真实脱敏案例数量为 0，因此只能条件通过。
- 1 万行基准完整跑通，其中 Excel 审核底稿导出耗时约 150.924 秒；5 万行已完成
  生成、导入、分页、搜索、异常检测、匹配和双向校核，但导出阶段达到约 33 分钟、
  约 2.5 GB 物理内存后由安全取消机制收束；20 万行未开始。该现场报告标记为
  `cancelled`，不构成性能门槛通过。
- macOS arm64 DMG 已通过 hdiutil、arm64、ad-hoc 签名、SHA-256 和隐私审计；
  当前没有 Developer ID 签名或 Apple 公证。

## 尚未关闭的生产门槛

1. 经过授权、脱敏和 SHA-256 核验的真实黄金案例仍未登记。
2. WPS macOS、WPS Windows、Microsoft Excel macOS 和 Microsoft Excel Windows
   的真机打开、重算、字体、筛选、打印和 Evidence 跳转记录仍需完成。
3. 1 万、5 万、20 万行的完整目标机器现场报告仍需完成，包括耗时、内存、
   取消延迟、数据库一致性、恢复和半成品清理。
4. 当前 macOS 安装包使用 ad-hoc 本地签名，尚未完成 Developer ID 签名和 Apple 公证。
5. Windows 原生安装包、跨独立项目库的企业知识中心和真实材料 Word 逐页检查尚未完成。

以上门槛关闭前，v0.1.10 不能标记为正式生产版。

发布检查使用的环境标识为：WPS macOS、WPS Windows、macOS Excel、Windows Excel、
1万、5万和20万行。上述标识只列明待验收范围，不表示已经通过。

## 安装和兼容

macOS Apple Silicon 预发行资产名为：

```text
Jiadun-0.1.10-macos-arm64.dmg
```

源码运行：

```bash
uv sync --python 3.12
uv run jiadun
```

旧 `costguard` 图形命令继续作为迁移兼容入口。GitHub 仓库地址、历史 tag、Release、
旧项目目录和旧导出文件保留原名称。升级不会删除、覆盖或移动原始工程资料。
