# Jiadun（价盾）v0.1.34 — 工程量核对第一批安全修复

本版为预览候选 / Prerelease，不代表正式生产版。

## 变化与依据

- 同量纲单位别名和倍率确定性换算：1 吨 + 500 千克 = 1.5 t；支持 100m²、10m³ 等。标准数量、原值、系数、行号和依据保留，原始数量/单价/金额不覆盖。
- 项目特征冲突、单位跨量纲或缺失、数量不可解析时，不输出可比累计数量与加权单价。原始金额仍保留为独立核查路径，不把金额可用解释为核量通过。
- 修复连续同名异码归并丢成员、模糊合并后重复返回被吸收组及合并后绕过单位/特征检查。保存前校验成员唯一和项目归属。
- 镜像模型与匹配详情只读取保存的成员，不按编码/名称扩大范围。空成员或缺一侧保持待补；同侧同口径明细数量/金额求和，不能将两个 60 去重成 60。
- Excel 对上对下对比复用聚合引擎；累计表显示标准单位。

镜像页仍是候选复核页，不代表多分包、多期有效结算数量台账。普通匹配按方向隔离；尚未明确选入跨方向成员时，镜像缺一侧属于保守边界。

## 口径、兼容和回滚

标准数量统一到 t、m、m2、m3；标准加权单价以有效金额/标准数量计算。金额来源、金额×数量校核与原始值保持既有规则。
计量对象特征采用去空白、Unicode 标准化后的精确一致；不猜测 C30/C35、厚度、密度或措施面积口径。
无数据库 migration。旧运行因程序版本变化退出当前结果，重跑生成新运行；历史 Evidence 保留。
可回装 v0.1.33，保留项目备份和原件。
