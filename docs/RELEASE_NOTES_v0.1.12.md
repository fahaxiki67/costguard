# Jiadun（价盾）v0.1.12 — 实际使用入口与解析失败闸门预发行

## 本版定位

v0.1.12 是 v0.1.11 证据边界版本之上的实际使用修复预发行版和预览候选。重点解决
“启动即出现大量项目”“文件选择器无法选文件”和“资料目录无法直接导入”
三个现场问题，并把解析失败保留为可追溯的项目状态。本版仍为
Preview/Prerelease，只适合合成或已经授权脱敏资料的试用、规则验证和流程反馈，
不代表正式结算、付款、责任、审批或经营结论。

## 主要变化

### 空白启动与项目边界

- 启动页默认只显示用户明确指定的当前工作空间，不再隐式扫描已记忆的临时
  工作空间或旧版 CostGuard 工作空间；因此测试目录、历史演示目录不会把首页灌满。
- 该行为只改变“启动时显示范围”，不删除、不移动、不改写任何旧项目数据库、
  原始文件或历史导出。用户可通过 **打开已有项目…** 明确选择包含 `project.db`
  的目录恢复项目。
- core 层创建/打开项目时只把工作空间登记为可恢复历史；只有用户在界面中
  明确确认的工作空间才成为启动页当前工作空间。

### 文件、文件夹与拖拽导入

- 首页新增 **导入资料文件…**、**导入资料文件夹…** 和拖拽区；空项目可在
  选择资料后先命名，再自动创建项目并导入只读副本。
- 工作台新增资料文件夹导入和拖拽区；可把文件或文件夹直接追加到当前项目。
- 文件夹递归扫描、按真实路径去重、不跟随符号链接路径/目录/文件，并跳过
  Finder/Office 临时文件。未支持的类型、链接和不可读取路径会在导入结果中明确
  显示，不会静默算作成功。
- 混合资料目录按类型路由：XLSX/XLSM/XLS/CSV 进入结算导入，DOCX/PDF/TXT
  进入合同/纪要文本提取；解析器仍由确定性 core 负责，AI 不参与金额计算或最终结论。
- **打开已有项目…** 与资料导入入口分开。项目目录选择器只接受含 `project.db`
  的目录；资料文件选择器接受单个或多个支持的源文件。
- 损坏工作簿和部分工作簿不再被界面计入“成功导入”；导入结果会分别显示成功、
  部分导入和失败文件，并保留解析错误与待人工确认说明。

### 字体与解析失败

- QApplication 统一设置平台可用的界面字体：macOS 优先 PingFang SC，Windows
  优先 Microsoft YaHei UI，其他平台优先 Noto Sans CJK SC，并按实际安装情况回退。
  字体族不写死在 QSS 中，避免跨平台出现不存在字体或中英文跳变。
- 结算工作簿解析失败会持久化 `parse_batches` 失败记录和 `parse_failure` Evidence，
  重新打开项目仍可看到失败原因，项目状态保持 fail-closed；同一文件后续成功重试
  后，旧失败批次仍留在历史中，不再污染当前状态。

## 计算、证据和 AI 边界

- 金额、数量、单价及差额继续全部使用 Decimal，业务计算不使用 float。
- 原始文件永不修改；导入副本、Sheet、行列和计算过程继续通过 Evidence 追溯。
- 缺失资料保持“待补资料”，不可比保持“不可比”，不以 0 补齐、不强制调平。
- AI 只可辅助语义候选、条款分类和文字解释，不承担金额计算、最终匹配、自动
  补缺、正式结论或责任判断。

## 验证记录与发布边界

- 本地自动化回归：全量 pytest、Ruff、UI 离屏启动、单文件导入、混合文件夹路由、
  解析失败重试隔离均通过。
- 合成黄金回归可用于验证执行器；真实脱敏黄金案例当前仍为 0，不能替代真实项目验收。
- WPS macOS、WPS Windows、macOS Excel、Windows Excel 的打开/重算/中文字体/筛选/
  打印/Evidence 跳转仍需现场记录。
- 1万、5万、20万行导入、搜索、异常、匹配、校核、Excel 导出、进度、取消和
  半成品清理仍需现场记录；未执行的规模门禁不得写成通过。
- Developer ID 签名、Apple 公证、跨系统安装与异常恢复仍未完成，当前构建为
  macOS Apple Silicon ad-hoc 本地签名预览版。

关闭以上生产门槛前，v0.1.12 不能标记为正式生产版。

## 安装和兼容

macOS Apple Silicon 预发行资产：

`Jiadun-0.1.12-macos-arm64.dmg`

下载后使用同一 Release 中的 `SHA256SUMS.txt` 校验。旧 `costguard` 图形命令、
GitHub 仓库地址、历史 tag、旧项目目录和旧导出文件保留兼容意义；升级不会删除、
覆盖或移动原始工程资料。
