# Jiadun（价盾）v0.1.13 — 校核独立性与可信度闸门预发行

v0.1.13 是面向真实工程结算复核的可信度收口预发行版和预览候选。重点是让“数值碰巧相等”
不能掩盖漏行、重复、隐藏、公式缓存或控制范围不明；本版暂不扩展 CAD、BIM、ERP
或在线协作等高级功能。

本版仍为 Preview/Prerelease，只适合经过授权的试用、合成回归和脱敏资料验证。没有
脱敏真实黄金案例、四种 Office 真机记录、目标规模性能、签名与公证证据前，不得将
本版解释为正式生产版或某个项目的结算审批结论。

## 本版完成

- A 路径继续从清洗明细汇总，B 路径改为直接扫描不可变 `raw_cells`，两条路径分别
  记录文件、SHA-256、Sheet、物理行号、数据范围和过滤条件；A/B 数值一致不再单独
  代表范围完整。
- C 路径从源表控制行的原始单元格重新读取，保留原始行列、原值、公式/缓存状态和
  来源 Evidence；唯一合计级行与无合计级时页级小计互斥求和的说明保持一致。控制值
  缺失、不唯一、无法定位或来源不一致时为“校核不充分”。
- 覆盖证明新增/固化原始数据区、有效明细、排除小计、标题、说明/备注、空白、待确认、
  解析失败、最终累计行数及各层金额；重复表头、表头前疑似业务行、多候选表头不能
  被人工映射静默抹掉。
- `.xlsx` 的公式缓存、筛选、表格范围、合并单元格和隐藏行列继续保留结构证据；
  `.xls` 因 xlrd 无法保留公式/合并/筛选拓扑而降级为“部分解析”，只能预览和人工
  复核，不能形成充分校核。
- 隐藏行/列在自动导入时进入待确认；用户明确给出数据范围后可以重放抽取，旧规范
  明细不会重复追加。人工确认会绑定当前操作人、范围和原因，并将可见性闸门吸收进
  当前覆盖证明；隐藏行列原始元数据仍保留在 Evidence 中。人工范围还必须覆盖表头后
  的全部非空物理行，漏掉尾部明细或控制行时，期次和项目摘要会统一保持“校核不充分”。
  数据区明细与控制行之间的内部空白/说明行进入待人工确认，表头多层结构的前置空行仍
  按表头范围证据处理；人工确认的已解决隐藏风险会保留在证明原因中，不覆盖其它结构风险。
- C 路径的 Evidence 会记录本次实际采用的控制规则，并用“C 原表唯一合计级行”“C 原表
  页级小计互斥汇总”或“C 控制值不可用”区分来源，避免把互斥分支写成同一条泛化口径。
- 正式分析入口固定先做 A/B/C 校核，再做异常检测；任何阶段技术失败都会返回
  `fail_closed`，异常、匹配和导出不能绕过校核闸门。
- 黄金回归继续采用闭世界比较并新增 `docs/GOLDEN_BASELINE_CHANGELOG_v0.1.13.md`，
  记录旧/新字段差异与原因；黄金执行器不自动更新基线。

## 使用限制

原始文件保持只读，缺失金额不会补 0，不可比和待确认项目不会强行匹配。AI（如启用）
仅可用于语义候选和文字解释，不参与金额、数量、税率、最终匹配或正式结论。任何
“校核不充分”“有条件结论”“待补资料”均需由业务人员结合原始 Evidence 继续复核。
