# Jiadun（价盾）v0.1.28 — Sheet 清单浏览器界面预发行

## 本版定位

v0.1.28 是在 v0.1.27 基础上的「任务 B 界面侧」版本，任务 B 主体至此闭环
（用户反馈#2/#5 的界面部分），仍为预览候选。macOS Apple Silicon 仍是
P0 主平台，Windows x64 仍是 P1。本版不标记为正式生产版。

## 主要变化

### 全工作簿 Sheet 清单浏览器（工作台新按钮「全工作簿 Sheet 清单…」）

- 列出项目全部 Sheet（每文件最新批次），附可见状态（历史批次显示「未知」，
  不默认可见）、行列数、状态、建议角色、置信度（高/中/低）、建议理由
  （含表头特征提示）与当前人工标注。
- 过滤：关键字（按 Sheet 名）、仅待确认、仅建议参与分析、全部。
- 人工标注：选中行后下拉选择清单类型（分部分项/单价措施/总价措施/对上
  明细/对下明细/其他费用/汇总页/非业务/暂不确定），理由必填并写入审计
  Evidence（记录来源文件+哈希+机器建议+人工理由）。
- 与 v0.1.27 的服务层联动：机器建议不覆盖人工标注；重解析时同名且内容
  一致的 Sheet 自动保留人工确认；角色变更使既有运行结果失效并要求重新
  校核。

### 继承能力

v0.1.27 服务层（清单服务/结转/合同失效联动）、v0.1.26 性能修复与缓存层
及之前的全部能力保留。

## 升级影响

无数据库迁移（schema 保持 v54）；旧项目直接打开，无数据变化。首次打开
新工作台按钮即可用；历史批次 Sheet 的可见状态显示「未知」属预期，重新
导入后即可获得。

SHA256SUMS.txt。不要将 PENDING / NOT VERIFIED 误读为已通过的真机能力。
