# Jiadun（价盾）v0.1.32 — 暖炭黑与红橙统一工作台预发行

## 本版定位

v0.1.32 基于 v0.1.31，将桌面界面统一为暖炭黑背景、暖白文字和红橙强调色。
本版保持预览候选 / Prerelease，不代表正式生产版。

## 主要变化

- 参考 PyQtDarkTheme 与 QDarkStyleSheet 的分层配色和控件状态处理，增加总览指标卡片、
  标签页选中底色、输入禁用态、横向滚动条悬停与按下态；来源见
  [主题参考记录](UI_THEME_REFERENCES.md)。

- 全局主题覆盖项目列表、期次概览、清单明细、审核问题中心、匹配复核、成果导出、
  版本与历史资产、资料中心及应用内对话框。
- 表格隔行、选中态、输入框、按钮、菜单、滚动条和进度条采用统一深色层次；
  Qt Fusion 与 palette 统一原生控件外观。操作系统文件选择器遵循系统设置。
- 保留成功、警告、风险三类语义色与文字，正文、主要按钮、选中行和状态徽章
  由回归检查保证至少 4.5:1 对比度。
- 重新生成真实程序的合成演示截图，补齐资料中心与版本历史页。

沿用 v0.1.31 的业务功能与证据边界。无计算口径变化，无数据库 migration。
如需回滚界面，可重新安装 v0.1.31；本版不改动原始文件。

## 验证范围
