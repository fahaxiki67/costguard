# Jiadun（价盾）v0.1.33 — 双小狗首页预发行

## 本版定位

v0.1.33 基于 v0.1.32，在启动后的项目首页欢迎区加入“小白与鸡毛”双小狗插图。
图案只有两只小狗，按参考图右侧小狗的短圆侧耳和脸型制作，沿用毛绒质感与红橙暖光；
透明背景融入现有工作台。
本版保持预览候选 / Prerelease，不代表正式生产版。

## 主要变化

- 首页显示白色“小白”与米黄色“鸡毛”，已列出项目时也保留欢迎插图。
- 插图随 macOS arm64 与 Windows x64 软件包分发，离线显示。
- 平台层统一定位源码与打包资源；资源缺失或损坏会明确报错。
- 新增透明背景、源码/打包路径与实际控件加载回归检查，补齐首次启动首页截图。

沿用 v0.1.32 的工作台颜色与业务功能。无计算口径变化，无数据库 migration。
回滚可重新安装 v0.1.32；本版不改动原始文件。

## 插图来源

插图由内置 imagegen 根据用户提供的参考图生成。用户指定两个角色为“小白”和
“鸡毛”，本图不代表官方角色素材或品牌授权。原始参考图片未随安装包分发。
生成提示与资源记录见 [首页插图记录](UI_MASCOT_ASSET.md)。

## 验证范围

发布前运行相关界面测试、全量 pytest、Ruff、版本/发布说明一致性和合成黄金回归，
并截取真实 Qt 界面核验布局。两个平台的构建工作流验证安装包，发布资产提供
SHA256SUMS.txt；自动化与合成样例不代替真实业务和 Office 环境验收。
