# Jiadun（价盾）v0.1.9 — 品牌迁移预发行

## 本版定位

v0.1.9 是在 v0.1.8 预览候选基础上的 Jiadun（价盾）品牌迁移版本。它把
用户可见名称、Python distribution、命令、macOS 应用和新生成成果统一为
`jiadun` / `Jiadun` / `价盾`，同时保留旧项目、旧结果和失败关闭边界的兼容读取。
本版仍是预发行版本，适合使用匿名或合成资料试用和反馈，不标记为正式生产版。

## 主要变化

- Python distribution 和源码包迁移为 `jiadun`，新的启动方式为 `uv run jiadun`
  或 `python -m jiadun`。
- macOS 应用和 DMG 使用 `Jiadun.app`、`Jiadun-0.1.9-macos-arm64.dmg`；
  应用显示名为「价盾」。
- 新配置目录、默认工作空间和导出文件采用 Jiadun 命名；旧 `CostGuard`
  配置、工作空间、运行失败侧车和历史导出只读兼容，不自动搬移、覆盖或删除。
- 旧 `costguard` GUI 命令保留为迁移兼容入口；GitHub 仓库地址、已有 v0.x 标签、
  `v0.1.8` Release 资产和 `costguard-canonical-json-v1` 黄金协议标识保持历史事实。
- Run Contract 中加入产品身份边界，品牌迁移不会把旧运行结果误当作当前结果。

## 验证与限制

本地已执行改名基线的自动化测试、Ruff、Python 编译、演示数据确定性、发布一致性
和 Jiadun 包构建检查。该验证不等同于以下环境门槛：

1. WPS 真机打开、公式重算和显示验证。
2. macOS Excel 真机打开、公式重算和显示验证。
3. Windows Excel 真机打开、公式重算和显示验证。
4. 1万、5万、20万行导入、搜索、异常、匹配、校核和导出性能，以及进度和安全取消。
5. Developer ID 签名、公证、发布 CI、版本迁移、备份恢复和异常退出恢复。
6. 脱敏真实案例黄金回归和外部验收。

在以上门槛关闭前，不能把 v0.1.9 称为正式生产版。程序主结论仍以确定性
`Decimal` 计算和 Evidence 为准；AI 不承担金额计算、最终匹配、自动补缺或业务责任判断。

## 使用与迁移

从本仓库源码运行：

```bash
uv sync --python 3.12
uv run jiadun
```

旧版 `costguard` 命令仅用于迁移兼容。已有 CostGuard 项目目录和历史导出请保留，
首次使用新版本时应核对项目、原始文件 SHA-256、Evidence 和当前 Run Contract，
确认无误后再开展新的校核。
